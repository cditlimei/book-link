# 换问法开关打开前：抽 10 到 20 道样题给家长看

第 9 章方案第 6 条规定，「同类题、专项换问法」默认关闭。打开前要做两件事：

1. AI 自检通过：家长 → 设置 → AI 学习教练 →「检查 AI 功能」，「出找错步题（标出错在哪一步）」和「全对的解答不判错（找错步）」两行都显示 ✅。
2. 家长抽看 10 到 20 道 AI 出的新问法样题，没问题再打开开关。

这份说明讲第 2 件事怎么做。样题要用真实的智谱密钥和孩子真实的错题才出得来，开发机上没有这两样，所以只能在家长自己的电脑上生成。回归测试 `observer_dd_6.py` 用打桩的 AI 测流程，测不了出题质量。

## 生成步骤（电脑上，约 3 分钟）

1. 用电脑上的 Chrome 或 Edge 打开 app。这台电脑上要已经填好智谱密钥，并且已经同步过，错题在本机。
2. 按 F12（Mac 按 ⌥⌘I）打开开发者工具，切到「Console / 控制台」。
3. 把下面这段整段粘进去，回车。用的是免费模型 GLM-4.6V-Flash，不花钱；发给模型的内容和平时做同类题一样，只有错题原文、知识点和错因。
4. 等 1 到 3 分钟。跑完后结果会打印在控制台，并复制到剪贴板（浏览器不让复制的话，从控制台手动复制）。

```js
(async () => {
  // 数学最近 8 道错题出「找错步」，每道再让模型独立复查一遍；英语最近 8 道轮流出四种问法
  const pick = (sid, n) => allItems().filter(it => it.sid === sid && (it.stem || it.tag)).slice(-n);
  const out = [];
  for (const it of pick('sx', 8)) {
    let r = null; try { r = await varGenForm(it, subjById('sx'), 'finderr'); } catch (e) {}
    if (!r) { out.push(`【数学·找错步】没出成（app 里会自动退回正常求解）\n原题：${it.stem || it.tag}`); continue; }
    let v = null; try { v = await finderrVerify(r.q); } catch (e) {}
    const chk = !v ? '复查没出结果' : v.err ? `复查认为第 ${v.step} 步有错` : '复查认为每一步都对';
    out.push(`【数学·找错步】原题：${it.stem || it.tag}\n${r.q}\n出题时标的错步：第 ${r.bad} 步；${chk}${v && v.err && v.step === r.bad ? '' : '  ← 两次不一致，重点看'}`);
  }
  let i = 0;
  for (const it of pick('yy', 8)) {
    const f = FORMS.yy[i++ % FORMS.yy.length];
    let r = null; try { r = await varGenForm(it, subjById('yy'), f); } catch (e) {}
    out.push(`【英语·${FORM_N[f]}】原题：${it.stem || it.tag}\n${r ? r.q : '没出成'}`);
  }
  const txt = out.join('\n\n----\n\n');
  console.log(txt);
  try { await navigator.clipboard.writeText(txt); } catch (e) {}
  return `共 ${out.length} 道`;
})()
```

这段代码只调出题函数，不写数据库，不改设置，不同步，孩子的记录里不会多出东西。要多抽几道就再跑一次，每次出的题不一样。

## 抽看时看什么

数学「找错步」，每道看 4 点：

- 标出的那一步确实是错的。
- 其余每一步都是对的。
- 错法和原题的错因对得上，比如原题去括号漏乘，这道题错的也是去括号。
- 改对那一步以后，题有唯一的正确答案。

标着「两次不一致，重点看」的先看。

英语四种问法，每道看 3 点：

- 题干本身没有语法错误。改错题故意留的那一处除外，而且全句只能有这一处错。
- 考的确实是原题那个易错点。
- 答案唯一，或者能明确判对错。造句题只要求用上给定的词或句型。

## 怎么判

- 20 道里有 2 道以上明显出错（标的错步其实是对的，或者英语题干自身有错），先别打开，把有问题的题发给开发调提示词。
- 只有 1 道出错，再跑一次，又抽 10 道都没问题，就可以打开。
- 打开的位置：家长 → 设置 → AI 学习教练 →「同类题、专项换问法」点「开」。开了以后发现问题，随时点「关」，关上后同类题和专项恢复成原来的样子。
